# Neural JARVIS Advanced Build Matrix

Repository: dragonballls/fullstack-agent
Branch: feat/jarvis-neural-space

This matrix records the advanced systems requested for Neural JARVIS Build #2. The
machine-readable source of truth is quality_of_life/neural_advanced.py::FEATURES.
Each listed capability has an executable runtime primitive, bridge command, or
simulation/analytics contract. Windows/GPU/XR/audio/provider-specific execution is
kept behind adapters so unsupported hardware does not break the core world.

## Core / Neural
Living computational organism behavior; fine-filament complexity; surrounding data
structures; priority-driven core reorganization; surface-tension cohesion; elasticity;
local turbulence; satellite droplets; mitosis; neuron growth; apoptosis; liquid
reconnection; magnetic relationships; spatial ecology; continuously evolving ecosystem;
ripples; waves; activity current; full fluid-environment simulation.

## Spatial windows / applications
Rotation; physical jiggle; elastic movement; curved surfaces; giant virtual walls;
monitor-wall navigation; grouping; stacking; tiling; snapping; freeform positioning;
group move/resize/rotate/hide/restore; anchoring and tethers; collision/occlusion;
z-order; orientation persistence; hybrid compositor; detached/reattached surfaces;
monitor-wall workspace.

## Desktop <-> 3D
Desktop-to-3D and 3D-to-desktop transitions, smooth handoff, focus preservation,
camera/layout handoff.

## Cross-application
Semantic drag/drop contracts for files, URLs, code, artifacts, workflows and tasks;
destination suggestions; cross-app intelligence; browser-to-code and build/artifact
movement.

## Browser / games
Research walls, side-by-side and multi-page layouts, session reconstruction, learned
browser profiles and browser resource tracking; learned game profiles, game quality
and capture strategy, profile migration, giant immersive surfaces, and Minecraft
profile learning.

## Performance and performance intelligence
CPU/RAM/GPU/VRAM/disk/network/thermal/battery/frame/capture sampling; per-window and
per-neuron accounting; baselines; before/after measurements; historical analytics;
memory-growth and GPU-spike tracking; bottleneck analytics; throttling; driver/GPU
assignment awareness; mixed refresh/resolution; ultrawide; iGPU/dGPU policy;
resource reservation; refresh optimization; adaptive refraction/bloom/glow; texture
and geometry streaming contracts; asset prewarming; variable-rate-shading readiness.

## Hardware / display
Display discovery state, arrangement persistence, disconnect/reconnect recovery,
per-display scaling, DPI/refresh/orientation state, display-aware placement and a
multi-display world contract.

## Search / navigation / lifecycle
History-aware semantic search scoring, camera/layout tracking hooks, slow-motion
inspection contract, dependency/usage state, continuous behavior/resource learning,
re-profiling, migration, regeneration, drift detection, differentiation/growth events.

## Memory / planning / reliability
Bookmarks; historical snapshots; layout/application restoration; relationship decay;
pruning and memory health; dry runs; projected paths; safe simulation; known-good
restore; impact analysis; sleep/wake recovery; monitor-change recovery; long-session
generation tracking; regional/selective reset; schema migration.

## Developer tools
Relationship, permission, lifecycle, performance, render-cost, physics-cost,
capture-cost, event-origin, task, provider, spatial-coordinate, world-state and
timeline inspectors.

## Remote / XR / accessibility
Remote machine/process/performance/cloud-service regions and reconnect state; spatial
audio and same-world XR readiness; camera/interaction sensitivity, captions,
transcripts, reduced-motion/transparency, UI/text scaling, hologram intensity,
high-contrast and mouse fallback parity. XR feature flags exist for eye gaze,
head tracking, controllers, 3D mouse, haptics, AR, VR and mixed reality without
requiring those devices on CI.

## Audio
Spatial/directional voice events plus neuron/search/workflow/handoff/error/ambient
event channels, activity-driven intensity, adaptive audio performance policy and
game-audio priority policy. The runtime emits structured audio events; an actual
device playback adapter remains platform-specific.

## Multi-user
User profiles, profile workspaces/layouts/pinned-neuron preferences, private/shared
brain regions, ownership indicators and shared-resource controls.

## Time machine / world streaming / large-world proof
Historical comparison and replay data contracts; dynamic region queues, cache,
unload, priority streaming and bounded virtual-world state; synthetic large-world
benchmarks for neurons, connections, windows, tasks, GPU/CPU/RAM/VRAM/capture and
performance scenarios.

## Simulation
Synthetic neurons, clusters, windows, tasks and relationships plus deterministic
physics/search/capture/performance benchmark scenarios.

## Verification requirements
The advanced subsystem is dependency-light and covered by tests/test_neural_advanced.py.
The existing full regression matrix, packaged Windows release gate, protected Build #1,
capability policy and provider authorization boundaries remain in force.
